# SNC — Official Streetwear Website

A responsive React + TypeScript website for SNC, an independent streetwear label.

## Stack
- React 18 + TypeScript
- Vite 6
- GSAP + ScrollTrigger for scroll-led motion
- Three.js for the interactive metallic object
- Lucide icons

## Local development
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

## Current implementation
- Responsive brand landing page and navigation
- Brand identity, world, collection and manifesto sections
- Three.js object with reduced-motion and WebGL fallback handling
- Product detail view with size and color selection
- Preview shopping bag with quantity controls
- Original vector product preview assets

## Before accepting real orders
Product names, product images, sizes, colors and prices must be confirmed against the final SNC catalogue. Checkout, inventory, payment processing, customer accounts, shipping, returns and contact destinations are not connected yet. The bag is deliberately a preview and must not be presented as a live store.
